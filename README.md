## Website

- Live: https://mayto05.github.io/first-baptist-loup-city/
- The page is a single self-contained `index.html` — easy to move to any hosting or a custom domain.
- While the site is a gift awaiting the church's acceptance it carries a `noindex` tag; once accepted, the tag is removed and search engines can index it.
